## 📌 НАЗНАЧЕНИЕ СИСТЕМЫ

**«Автошкола-Эксперт» (DriveSecure)** — это веб-ориентированная информационная система, автоматизирующая ключевые процессы подготовки водителей транспортных средств категорий A, B, C с математически гарантированной защитой от фальсификации результатов экзаменов и строгим соблюдением Федерального закона № 152-ФЗ «О персональных данных».

### Основные функциональные модули:
1. **Запись на практическое вождение:**
   - Каталог аттестованных инструкторов и автопарка (МКПП и АКПП);
   - Интерактивный календарь на базе **FullCalendar JS** для бронирования слотов времени;
   - Кабинет инструктора: управление графиком, отметка о проведении занятий с начислением практических учебных часов курсанту;
   - Серверный контроль тарифов (защита от Price Tampering).
2. **Тренажер правил дорожного движения (ПДД РФ):**
   - 40 официальных экзаменационных билетов (800 вопросов с 4 вариантами ответов);
   - Интерактивный режим тренировки с моментальной проверкой ответов по AJAX и выводом правовых комментариев;
   - Официальный внутренний теоретический экзамен: 20 случайных вопросов, таймер 20 минут, не более 2 ошибок.
3. **Учет внутренних экзаменов (Теория и Практика):**
   - Прием практического экзамена экзаменатором (автодром и городской маршрут с учетом штрафных баллов до 4 баллов включительно);
   - Электронный реестр протоколов экзаменов.
4. **Комплексная подсистема информационной безопасности:**
   - **Цифровая подпись HMAC-SHA256:** защита каждого экзаменационного протокола от подделки;
   - **Блокчейн-цепочка хешей (Hash-Chaining):** гарантирует невозможность удаления или подмены протоколов задним числом;
   - **Интерактивный сканер целостности БД (`/admin/integrity`):** сквозной аудит всех записей СУБД с детекцией фальсификаций и симулятором атак для демонстрации;
   - **Симметричное шифрование Fernet (AES-128-CBC + HMAC-SHA256):** шифрование телефонов, паспортных данных и медсправок в покое (at rest);
   - **Сессионная безопасность:** 15-минутные защищенные токены в БД с функцией принудительного отзыва (Instant Revocation);
   - **Защита от XSS (Bleach) и CSRF (Flask-WTF).**

## 🚀 БЫСТРЫЙ ЗАПУСК ПРОЕКТА

### 1. Клонирование репозитория
```bash
git clone git@github-second:Daniil74455/course_work.git
cd course_work
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
*(В файле `.env` уже преднастроены валидные криптографические ключи Fernet и HMAC).*

### 4. Инициализация и сидирование базы данных (5000+ записей)
```bash
python3 seed_db.py
```
Скрипт автоматически создаст схему таблиц и сгенерирует:
* 113 пользователей;
* 800 вопросов ПДД (40 билетов);
* **5 200 слотов вождения** (выполнение кафедрального норматива $\ge 5000$);
* 4 688 бронирований занятий;
* 120 подписанных HMAC-SHA256 протоколов экзаменов.

### 5. Запуск веб-сервера
```bash
python3 app.py
```
Приложение доступно по адресу: **http://127.0.0.1:5000**

## 🧪 ТЕСТИРОВАНИЕ СИСТЕМЫ (PYTEST)

Запуск набора автоматизированных тестов информационной безопасности:
```bash
pytest -v
```
Все 8 тестов выполняются менее чем за 1 секунду:
* Проверка соленого хеширования паролей PBKDF2-HMAC-SHA256;
* Проверка шифрования ПДн Fernet at rest;
* Проверка валидности HMAC-подписи и блокчейн-цепочки;
* Проверка детекции фальсификации оценки в СУБД;
* Проверка детекции разрыва хеш-цепочки;
* Проверка санитизации Stored XSS через Bleach;
* Проверка ролевой модели RBAC;
* Проверка таймаута и отзыва сессий.

## 🔒 АРХИТЕКТУРА ИНФОРМАЦИОННОЙ БЕЗОПАСНОСТИ

```
Пользовательский запрос (HTTP)
   │
   ├── [1] Проверка CSRF-токена (Flask-WTF)
   │
   ├── [2] Перехватчик сессий (@app.before_request):
   │       ├── Проверка срока жизни токена (15 минут)
   │       └── Проверка статуса отзыва администратором (UserSession.is_active)
   │
   ├── [3] Авторизация и матрица доступа (@role_required: RBAC)
   │
   ├── [4] Санитизация входящих данных (Bleach): удаление XSS-векторов
   │
   ├── [5] Контроллер бизнес-логики (ORM SQLAlchemy: исключение SQLi)
   │
   ├── [6] Уровень хранения данных (СУБД):
   │       ├── ПДн курсантов: Симметричное шифрование Fernet (AES-128-CBC)
   │       ├── Пароли: PBKDF2-HMAC-SHA256 с индивидуальной солью
   │       └── Протоколы экзаменов:
   │             ├── Цифровая подпись HMAC-SHA256 (защита от фальсификации)
   │             └── Блокчейн-цепочка Hash-Chaining (prev_hash -> record_hash)
   │
   └── [7] Административный сканер целостности БД: автоматическая детекция подделок
```
